# INSTALL_PROXY.md

# Installing the Coirtx Proxy

This document explains how to install and configure the **Coirtx Proxy** after it has already been built and installed from source.

> **Prerequisite**
>
> Complete all steps from **BUILD_PROXY.md** before continuing.

---

# Overview

The installation consists of the following stages:

1. Create runtime directories
2. Create the SQLite database
3. Create the Coirtx service account
4. Configure the proxy
5. Set permissions
6. Create the systemd service
7. Start the proxy
8. Register the proxy in the Coirtx Server
9. Verify operation

---

# 1. Create Runtime Directories

The proxy stores its SQLite database and log files locally.

Create the required directories:

```bash
sudo mkdir -p /var/lib/coirtx
sudo mkdir -p /var/log/coirtx

```

---

# 2. Create the SQLite Database

Generate the database from the SQLite schema produced during the build process.

```bash
make dbschema

sudo sqlite3 /var/lib/coirtx/coirtx_proxy.db \
    < database/sqlite3/schema.sql
```

Verify that the database was created successfully.

```bash
sqlite3 /var/lib/coirtx/coirtx_proxy.db ".tables"
```

You should see hundreds of tables beginning with names such as:

```
actions
alerts
config
hosts
items
proxy
proxy_history
triggers
...
```

This confirms that the proxy database has been initialized successfully.

---

# 3. Create the Coirtx Service Account

Running the proxy as **root** is not recommended.

Create a dedicated system user and group.

```bash
sudo /usr/sbin/groupadd --system coirtx

sudo /usr/sbin/useradd \
    --system \
    --gid coirtx \
    --home-dir /var/lib/coirtx \
    --shell /usr/sbin/nologin \
    --comment "Coirtx Monitoring" \
    coirtx
```

Verify:

```bash
id coirtx
```

Example:

```
uid=997(coirtx)
gid=989(coirtx)
groups=989(coirtx)
```

If the user already exists, this step can be skipped.

---

# 4. Configure the Proxy

The default configuration file is installed at

```
/etc/coirtx/zabbix_proxy.conf
```

Open it:

```bash
sudo nano /etc/coirtx/zabbix_proxy.conf
```

Modify the following parameters.

---

## Proxy Mode

```
ProxyMode=0
```

`0` means **Active Proxy**.

The proxy connects to the server and downloads its own configuration.

---

## Server Address

```
Server=10.130.6.248
```

Replace this with the IP address (or DNS name) of your Coirtx Server.

---

## Proxy Hostname

```
Hostname=OIRT-CCTV-PROXY
```

This **must exactly match** the proxy name created inside the Coirtx frontend.

The hostname is case-sensitive.

---

## SQLite Database

Replace

```
DBName=zabbix_proxy
```

with

```
DBName=/var/lib/coirtx/coirtx_proxy.db
```

This points the proxy to the SQLite database created earlier.

---

## Log File

Change

```
LogFile=/tmp/zabbix_proxy.log
```

to

```
LogFile=/var/log/coirtx/coirtx_proxy.log
```

---

## Recommended Synchronization Settings

```
ConfigFrequency=10
DataSenderFrequency=1
```

These values allow configuration changes and collected data to synchronize quickly during development and testing.

---

# 5. Set Ownership

Give the service account access to the required directories.

```bash
sudo chown -R coirtx:coirtx /var/lib/coirtx
sudo chown -R coirtx:coirtx /var/log/coirtx
sudo chown -R coirtx:coirtx /etc/coirtx
```

Verify:

```bash
ls -ld /var/lib/coirtx
ls -ld /var/log/coirtx
```

The owner should be:

```
coirtx coirtx
```

---

# 6. Create the systemd Service

Create the service file.

```bash
sudo nano /etc/systemd/system/coirtx-proxy.service
```

Insert:

```ini
[Unit]
Description=Coirtx Proxy
After=network.target

[Service]
Type=simple
User=coirtx
Group=coirtx

ExecStart=/opt/coirtx/sbin/zabbix_proxy \
    -c /etc/coirtx/zabbix_proxy.conf \
    -f

Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Save the file.

---

# 7. Enable and Start the Service

Reload systemd:

```bash
sudo systemctl daemon-reload
```

Enable the proxy:

```bash
sudo systemctl enable coirtx-proxy
```

Start it:

```bash
sudo systemctl start coirtx-proxy
```

Check its status:

```bash
systemctl status coirtx-proxy
```

Expected:

```
Active: active (running)
```

---

# 8. Verify the Log File

Monitor the proxy log.

```bash
tail -f /var/log/coirtx/coirtx_proxy.log
```

On a successful connection you should eventually see messages indicating that:

* the proxy connected to the server,
* configuration was downloaded,
* data synchronization started.

---

# 9. Register the Proxy in the Coirtx Server

Open the Coirtx frontend.

Navigate to:

```
Administration
    → Proxies
```

Create a new proxy.

| Field   | Value           |
| ------- | --------------- |
| Name    | OIRT-CCTV-PROXY |
| Mode    | Active          |
| Enabled | Yes             |

Save.

The **Name** must exactly match:

```
Hostname=OIRT-CCTV-PROXY
```

configured in `zabbix_proxy.conf`.

---

# 10. Assign Hosts to the Proxy

For every host that should be monitored through this proxy:

```
Host
    → Monitored by
        → Proxy
```

Select:

```
OIRT-CCTV-PROXY
```

Save the host.

---

# 11. Verify Connectivity

Open

```
Administration
    → Proxies
```

After a few moments the proxy should show as **Online**.

If the status remains **Offline**, inspect:

```bash
journalctl -u coirtx-proxy -f
```

or

```bash
tail -f /var/log/coirtx/coirtx_proxy.log
```

---

# Troubleshooting

## Proxy reports "major versions do not match"

The server and proxy **must use the same major version**.

Example:

* Server 8.0.x
* Proxy 8.0.x

A 7.x proxy cannot communicate with an 8.x server.

---

## Proxy remains Offline

Verify:

* `Server=` points to the correct Coirtx Server.
* `Hostname=` exactly matches the proxy name configured in the frontend.
* TCP port **10051** is reachable.
* The proxy service is running.
* The server has the proxy registered.

---

## SQLite database cannot be opened

Verify:

```
DBName=/var/lib/coirtx/coirtx_proxy.db
```

Also check file ownership:

```bash
ls -l /var/lib/coirtx
```

The database should be owned by:

```
coirtx:coirtx
```

---

## Permission denied

Ensure the following directories are writable by the `coirtx` user:

* `/var/lib/coirtx`
* `/var/log/coirtx`

---

# Installation Complete

At this point:

* ✓ The Coirtx Proxy is installed.
* ✓ The SQLite database has been initialized.
* ✓ The proxy is running as a dedicated service account.
* ✓ The proxy starts automatically on boot.
* ✓ The proxy is ready to be registered with the Coirtx Server and assigned to monitor remote hosts.
