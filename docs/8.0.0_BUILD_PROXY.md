# BUILD_PROXY.md

# Building Coirtx Proxy (8.0.0rc1) on Debian 13 (Trixie)

This guide builds only the Coirtx Proxy from source.

---

# 1. Install build tools

```bash
su -

apt update

apt install -y \
    build-essential \
    autoconf \
    automake \
    autopoint \
    libtool \
    pkg-config \
    gettext \
    bison \
    flex
```

---

# 2. Install required libraries

```bash
apt install -y \
    sqlite3 \
    libsqlite3-dev \
    libxml2-dev \
    libsnmp-dev \
    libevent-dev \
    libcurl4-openssl-dev \
    libpcre2-dev \
    zlib1g-dev
```

> Note:
>
> OpenIPMI support was intentionally disabled because it is not required for
> the CCTV proxy.

---

# 3. Bootstrap

```bash
git clone git@github.com:oirtstut/coirtx.git
cd coirtx
git checkout branding/coirtx

./bootstrap.sh
```

---

# 4. Configure

```bash
./configure \
    --prefix=/opt/coirtx \
    --sysconfdir=/etc/coirtx \
    --enable-proxy \
    --with-sqlite3 \
    --with-net-snmp \
    --with-libcurl \
    --with-libxml2
```

Expected summary:

```
Enable proxy:          yes

With database:         SQLite v3.x
SNMP:                  yes
WEB Monitoring:        cURL

Configuration file:
    /etc/coirtx/zabbix_proxy.conf
```

---

# 5. Build

```bash
make -j$(nproc)
```

---

# 6. Verify build

```bash
find src -type f -executable | grep proxy
```

Expected:

```
src/zabbix_proxy/zabbix_proxy
```

---

# 7. Install

```bash
su -

cd /home/oirt/wspace/coirtx

make install
```

---

# 8. Verify installation

```bash
ls -l /opt/coirtx/sbin/
```

Expected:

```
zabbix_proxy
```

Verify version:

```bash
/opt/coirtx/sbin/zabbix_proxy --version
```

Expected:

```
zabbix_proxy (Zabbix) 8.0.0rc1
```

---

# Next Steps

The proxy has been compiled successfully.

Remaining work:

- Configure `zabbix_proxy.conf`
- Create SQLite database
- Create runtime directories
- Create systemd service
- Register proxy with Coirtx server
- Verify proxy connectivity
- Begin monitoring hosts through the proxy

---

# 9. Prepare runtime directories

Create directories for the proxy database and log files.

```bash
su -

mkdir -p /var/lib/coirtx
mkdir -p /var/log/coirtx

chmod 755 /var/lib/coirtx
chmod 755 /var/log/coirtx
```

---

# 10. Configure the proxy

Edit the proxy configuration file.

```bash
nano /etc/coirtx/zabbix_proxy.conf
```

Update the following parameters:

```ini
ProxyMode=0

Server=10.130.6.248

Hostname=OIRT-CCTV-PROXY

DBName=/var/lib/coirtx/coirtx_proxy.db

LogFile=/var/log/coirtx/coirtx_proxy.log
LogFileSize=0

ConfigFrequency=10
DataSenderFrequency=1
```

Notes:

- `ProxyMode=0` configures the proxy in **active mode**.
- `Server` is the IP address of the Coirtx server.
- `Hostname` **must exactly match** the Proxy name configured in the Coirtx frontend.
- `DBName` is the SQLite database file that will be created automatically during initialization.
- `ConfigFrequency=10` causes the proxy to request configuration updates every 10 seconds.
- `DataSenderFrequency=1` sends collected data to the server every second, which is useful during testing.

---

# 11. Verify the configuration

```bash
grep -E '^(ProxyMode|Server|Hostname|DBName|LogFile|ConfigFrequency|DataSenderFrequency)' \
/etc/coirtx/zabbix_proxy.conf
```

Expected output:

```
ProxyMode=0
Server=10.130.6.248
Hostname=OIRT-CCTV-PROXY
DBName=/var/lib/coirtx/coirtx_proxy.db
LogFile=/var/log/coirtx/coirtx_proxy.log
ConfigFrequency=10
DataSenderFrequency=1
```

The proxy configuration is now ready.

The next step is to initialize the SQLite database and create the systemd service.
